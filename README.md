UYC (Untitled YouTube Client)

A YouTube client inspired by Facebook Watch, designed to be simple and easy to use.

<img width="1873" height="1018" alt="Captura de pantalla 2026-08-23 123122" src="https://github.com/user-attachments/assets/0e2dcc2d-d91a-4c45-8256-6266114cd8b3" />

Features:
•Share videos via social media or by copying the link
•Add videos to favorites
•Subscribe to new channels without a Google account
•Import and export subscriptions
•No Google account required
•Support for over 20 languages
•Neutral and white color scheme/theme

How to get it?
Visit https://angelgtz6249.github.io/UYC and enjoy

Run the following command: 

git clone https://github.com/angelgtz6249/UYC.git 

Then open the index.html file and enjoy
